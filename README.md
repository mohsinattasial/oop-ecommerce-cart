# E-Commerce Shopping Cart — Python OOP

A command-line learning project for products, quantities, totals and configurable discount strategies.

## Run
```bash
cd oop-ecommerce-cart
python cli.py
```

## Tests
```bash
cd oop-ecommerce-cart
python -m unittest discover -s tests -v
```

## Structure
- `oop-ecommerce-cart/cli.py`: CLI
- `oop-ecommerce-cart/src/models.py`: product data
- `oop-ecommerce-cart/src/cart.py`: cart calculations
- `oop-ecommerce-cart/src/strategies.py`: discount strategies
- `oop-ecommerce-cart/tests/test_cart.py`: unit tests

Educational code only; no payment processing. Author: Mohsin Atta.
